# Appointment Booking System (Web Application)

A simple and interactive **appointment booking web application** built using **HTML, CSS, and JavaScript**.
Users can book appointments, view them in a list, cancel them, and see the current date and time in real-time.

## Features

* Live date & time display
* Appointment booking form
* Input validation (no past dates/times)
* Display booked appointments
* Cancel appointment option
* Clean and user-friendly UI

## Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla JS)**

## How to Run

1. Download or clone the repository
2. Open `index.html` in any modern browser
3. Fill the form and book your appointment
